================================================================================
                    API SPECIFICATION - FUNDRAISING FEATURE
                           (Gây quỹ & Quyên góp)
================================================================================

Database Tables (cần tạo mới):
- fundraising_campaigns (chiến dịch gây quỹ)
- donations (khoản quyên góp)
- campaign_updates (cập nhật tiến độ)

Campaign Status: ACTIVE | PAUSED | COMPLETED | CANCELLED
Campaign Category: MEDICAL | RESCUE | SHELTER | FOOD | OTHER
Donation Status: PENDING | COMPLETED | FAILED
Payment Method: MOMO | ZALOPAY | BANK | CARD

================================================================================
                         3. CREATE CAMPAIGN
================================================================================
Create a new fundraising campaign

Endpoint: POST /api/v1/fundraising/campaigns
Auth: Required (Bearer Token)
Content-Type: multipart/form-data

Request Body:
{
  "title": "Cứu chó Husky bị tai nạn",           // required
  "description": "Mô tả ngắn...",                 // required
  "descriptionDetailed": "Mô tả chi tiết...",    // optional
  "category": "MEDICAL",                          // required
  "targetAmount": 5000000,                        // required
  "currency": "VND",                              // default VND
  "beneficiary": "Trạm Cứu Hộ PetAid",           // optional
  "endDate": "2024-12-31T23:59:59Z",             // optional
  "relatedPetId": 1                               // optional
}
+ image file (required)

Response 201 Created:
{
  "success": true,
  "data": { ... campaign object ... },
  "message": "Tạo chiến dịch thành công"
}

================================================================================

Endpoint: POST /api/v1/fundraising/campaigns/{id}/donate

================================================================================
                         DATABASE SCHEMA
================================================================================

-- fundraising_campaigns table
CREATE TABLE public.fundraising_campaigns (
  id int8 GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  title varchar(255) NOT NULL,
  slug varchar(255) NOT NULL UNIQUE,
  description text NOT NULL,
  description_detailed text,
  image varchar(500) NOT NULL,
  category varchar(50) NOT NULL,
  target_amount decimal(15,2) NOT NULL,
  current_amount decimal(15,2) NOT NULL DEFAULT 0,
  currency varchar(10) NOT NULL DEFAULT 'VND',
  beneficiary varchar(255),
  status varchar(20) NOT NULL DEFAULT 'ACTIVE',
  start_date timestamp NOT NULL DEFAULT NOW(),
  end_date timestamp,
  created_at timestamp NOT NULL DEFAULT NOW(),
  updated_at timestamp NOT NULL DEFAULT NOW(),
  user_id int8 NOT NULL REFERENCES public.users(id),
  pet_id int8 REFERENCES public.pets(id),
  CONSTRAINT campaigns_category_check CHECK (category IN ('MEDICAL', 'RESCUE', 'SHELTER', 'FOOD', 'OTHER')),
  CONSTRAINT campaigns_status_check CHECK (status IN ('ACTIVE', 'PAUSED', 'COMPLETED', 'CANCELLED'))
);

-- donations table
CREATE TABLE public.donations (
  id int8 GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  campaign_id int8 NOT NULL REFERENCES public.fundraising_campaigns(id),
  donor_id int8 REFERENCES public.users(id),
  amount decimal(15,2) NOT NULL,
  currency varchar(10) NOT NULL DEFAULT 'VND',
  message text,
  is_anonymous bool NOT NULL DEFAULT false,
  payment_method varchar(20) NOT NULL,
  payment_transaction_id varchar(100),
  status varchar(20) NOT NULL DEFAULT 'PENDING',
  created_at timestamp NOT NULL DEFAULT NOW(),
  CONSTRAINT donations_payment_check CHECK (payment_method IN ('MOMO', 'ZALOPAY', 'BANK', 'CARD')),
  CONSTRAINT donations_status_check CHECK (status IN ('PENDING', 'COMPLETED', 'FAILED'))
);

-- campaign_updates table
CREATE TABLE public.campaign_updates (
  id int8 GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  campaign_id int8 NOT NULL REFERENCES public.fundraising_campaigns(id),
  title varchar(255) NOT NULL,
  content text NOT NULL,
  images jsonb,
  created_at timestamp NOT NULL DEFAULT NOW()
);


================================================================================
                         BUSINESS RULES
================================================================================

1. Anyone can create a fundraising campaign (authenticated users only)

2. Donations:
   - Minimum amount: 10,000 VND
   - Can be anonymous (donor info hidden)
   - Supports multiple payment methods

3. Campaign status:
   - ACTIVE: Accepting donations
   - PAUSED: Temporarily paused by owner
   - COMPLETED: Target reached or manually closed
   - CANCELLED: Cancelled by owner or admin

4. When currentAmount >= targetAmount:
   - Auto-change status to COMPLETED
   - Notify campaign owner

5. Campaign owner can:
   - Add updates
   - Pause/Resume campaign
   - Close campaign

6. Only campaign owner can edit/delete their campaigns
