================================================================================
                    API SPECIFICATION - NEARBY & RESCUE CENTERS
                        (Gần bạn & Trung tâm cứu hộ)
================================================================================

Database Tables Used:
- pet_posts (bài đăng thú cưng)
- rescue_centers (trung tâm cứu hộ - cần tạo mới)
- users (thông tin người dùng)

================================================================================
                         DATABASE SCHEMA
================================================================================

-- rescue_centers table (cần tạo mới)
CREATE TABLE public.rescue_centers (
  id int8 GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name varchar(255) NOT NULL,
  address varchar(255) NOT NULL,
  district varchar(100),
  city varchar(100) NOT NULL,
  latitude float8 NOT NULL,
  longitude float8 NOT NULL,
  phone varchar(20) NOT NULL,
  email varchar(255),
  website varchar(255),
  hours varchar(100),
  description text,
  services jsonb,
  specialties jsonb,
  photos jsonb,
  rating float8 DEFAULT 0,
  review_count int4 DEFAULT 0,
  is_verified bool DEFAULT false,
  created_at timestamp NOT NULL DEFAULT NOW(),
  updated_at timestamp NOT NULL DEFAULT NOW(),
  user_id int8 REFERENCES public.users(id)
);

-- rescue_center_reviews table
CREATE TABLE public.rescue_center_reviews (
  id int8 GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  rescue_center_id int8 NOT NULL REFERENCES public.rescue_centers(id),
  user_id int8 NOT NULL REFERENCES public.users(id),
  rating int4 NOT NULL CHECK (rating >= 1 AND rating <= 5),
  comment text,
  created_at timestamp NOT NULL DEFAULT NOW(),
  CONSTRAINT uk_rescue_review UNIQUE (rescue_center_id, user_id)
);


================================================================================
                         BUSINESS RULES
================================================================================

1. Distance calculation:
   - Use Haversine formula for calculating distance
   - Return distance in kilometers

2. Nearby search:
   - Default radius: 10km for posts, 15km for rescue centers
   - Sort by distance (nearest first)

3. Rescue centers:
   - Can be registered by organization owners
   - Verified status granted by admin
   - Rating calculated from user reviews

4. Reviews:
   - One review per user per rescue center
   - User can update their review
   - Rating auto-recalculated on new review

5. Map data:
   - Only return items with valid coordinates
   - Limit to reasonable radius (max 50km)


================================================================================
                         GEOLOCATION NOTES
================================================================================

For frontend:
- Use browser Geolocation API to get user's coordinates
- Request permission before accessing location
- Handle permission denied gracefully
- Cache location for performance

For backend:
- Store coordinates as float8 (double precision)
- Create spatial index for performance:
  CREATE INDEX idx_posts_location ON pet_posts(latitude, longitude);
  CREATE INDEX idx_rescue_location ON rescue_centers(latitude, longitude);
