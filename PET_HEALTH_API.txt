================================================================================
                    API SPECIFICATION - PET HEALTH RECORDS
                           (Hồ sơ sức khỏe thú cưng)
================================================================================

Database Tables Used:
- pets (thông tin thú cưng)
- pet_health_records (hồ sơ sức khỏe)
- vaccinations (tiêm chủng)
- weight_tracking (theo dõi cân nặng)
- medical_history (lịch sử y tế)
- users (chủ sở hữu)

================================================================================
                         2. UPDATE HEALTH RECORD
================================================================================
Update pet's health record

Endpoint: PUT /api/v1/pets/{petId}/health
Auth: Required (pet owner only)

Request Body:
{
  "weight": 28.5,
  "allergies": ["Thức ăn có ngũ cốc", "Sữa"],
  "notes": "Cập nhật thông tin mới",
  "lastCheckup": "2024-12-15T00:00:00Z"
}

Response 200 OK:
{
  "success": true,
  "data": { ... health record ... },
  "message": "Cập nhật hồ sơ sức khỏe thành công"
}


================================================================================
                         3. ADD VACCINATION
================================================================================
Add a new vaccination record

Endpoint: POST /api/v1/pets/{petId}/health/vaccinations
Auth: Required (pet owner only)

Request Body:
{
  "name": "Distemper",                           // required
  "vaccinationDate": "2024-12-20T00:00:00Z",    // required
  "nextDueDate": "2025-12-20T00:00:00Z",        // optional
  "clinic": "Phòng khám ABC",                    // optional
  "veterinarian": "BS. Nguyễn Văn A",           // optional
  "notes": "Tiêm mũi nhắc lại"                  // optional
}

Response 201 Created:
{
  "success": true,
  "data": {
    "id": 3,
    "name": "Distemper",
    "vaccinationDate": "2024-12-20T00:00:00Z",
    "nextDueDate": "2025-12-20T00:00:00Z",
    "clinic": "Phòng khám ABC",
    "veterinarian": "BS. Nguyễn Văn A",
    "notes": "Tiêm mũi nhắc lại",
    "createdAt": "2024-12-20T10:00:00Z"
  },
  "message": "Đã thêm thông tin tiêm chủng"
}

Add a new medical history entry

Endpoint: POST /api/v1/pets/{petId}/health/medical-history
Auth: Required (pet owner only)

{

  "visitDate": "2024-12-18T00:00:00Z",          // required

{

  "data": { ... medical history entry ... },
  "message": "Đã thêm lịch sử y tế"
}


================================================================================
                         5. ADD WEIGHT TRACKING
================================================================================
Record pet's weight

Endpoint: POST /api/v1/pets/{petId}/health/weight
Auth: Required (pet owner only)

Request Body:
{
  "weight": 28.5,                                // required
  "recordDate": "2024-12-20T00:00:00Z",         // optional, default now
  "notes": "Sau đợt ốm"                         // optional
}

Response 201 Created:
{
  "success": true,
  "data": {
    "id": 3,
    "weight": 28.5,
    "recordDate": "2024-12-20T00:00:00Z",
    "notes": "Sau đợt ốm",
    "createdAt": "2024-12-20T10:00:00Z"
  },
  "message": "Đã ghi nhận cân nặng"
}


================================================================================
                         6. GET VACCINATION SCHEDULE
================================================================================
Get upcoming vaccination reminders

Endpoint: GET /api/v1/pets/{petId}/health/vaccinations/upcoming
Auth: Required (pet owner only)

Query Parameters:
  - days (optional): number, default 30 (next 30 days)

Response 200 OK:
{
  "success": true,
  "data": [
    {
      "id": 1,
      "name": "Rabies (Dại)",
      "nextDueDate": "2025-01-15T00:00:00Z",
      "daysUntilDue": 25,
      "status": "UPCOMING"  // UPCOMING | OVERDUE | COMPLETED
    }
  ]
}


================================================================================
                         7. GET PET QR CODE
================================================================================
Get QR code for pet health profile

Endpoint: GET /api/v1/pets/{petId}/qr-code
Auth: Required (pet owner only)

Response: image/png (binary data)

Note: QR code contains URL to public pet profile

================================================================================
                         BUSINESS RULES
================================================================================

1. Access control:
   - Only pet owner can view/edit health records
   - Public profile (via QR) shows limited info

2. Vaccination reminders:
   - Send notification 7 days before due date
   - Mark as OVERDUE if past due date

3. Weight tracking:
   - Store history for trend analysis
   - Alert if unusual weight change (>10% in 30 days)

4. Medical history:
   - Keep complete history
   - Cannot delete (only mark as inactive)

5. QR Code:
   - Generated once, cached
   - Contains public profile URL
   - Scan redirects to pet info page


================================================================================
                         FRONTEND DISPLAY
================================================================================

Pet Health Profile tabs:
1. Tổng quan (Overview):
   - Basic info, personality, special needs
   - Current health status
   - Last checkup date

2. Tiêm chủng (Vaccinations):
   - List of all vaccinations
   - Next due dates
   - Add new vaccination

3. Lịch sử (Medical History):
   - List of medical conditions
   - Treatment details
   - Add new entry

4. Chi tiết (Details):
   - Weight history chart
   - Medical notes
   - Allergies
