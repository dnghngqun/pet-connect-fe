================================================================================
                    API SPECIFICATION - PET POST FEATURE
                         (Quản lý bài đăng thú cưng)
================================================================================

Database Tables Used:
- pet_posts (main table)
- pets (pet information)
- media (images)
- users (author info)

Post Status (loại bài đăng): LOST | FOUND | FOR_ADOPTION | RESCUE

Lưu ý:
- Bài đăng mới sẽ hiển thị công khai NGAY sau khi tạo
- KHÔNG có tính năng lưu nháp (draft)
- KHÔNG cần duyệt bài

================================================================================
                              1. GET POSTS LIST
================================================================================
Get list of posts with filters and pagination

Endpoint: GET /api/v1/posts
Auth: Optional (public endpoint)

Query Parameters:
  - status (optional): LOST | FOUND | FOR_ADOPTION | RESCUE
  - petType (optional): string (e.g., "Chó", "Mèo")
  - city (optional): string (e.g., "TP. Hồ Chí Minh")
  - district (optional): string (e.g., "Quận 1")
  - search (optional): string (search in title, description)
  - featured (optional): boolean
  - page (optional): number, default 0
  - size (optional): number, default 10
  - sort (optional): string, default "createdAt,desc"

Request Example:
GET /api/v1/posts?status=LOST&city=TP. Hồ Chí Minh&page=0&size=10

================================================================================
                           4. CREATE POST
================================================================================
Create a new post

Endpoint: POST /api/v1/posts
Auth: Required (Bearer Token)
Content-Type: multipart/form-data (for images) or application/json

Request Body (JSON):
{
  "title": "Chó Husky mất tích tại Q.1, TP.HCM",            // required, max 255
  "description": "Mô tả chi tiết về thú cưng...",          // required, min 20 chars
  "petType": "Husky",                                       // required
  "status": "LOST",                                         // required: LOST|FOUND|FOR_ADOPTION|RESCUE
  "city": "TP. Hồ Chí Minh",                               // required
  "district": "Quận 1",                                     // optional
  "location": "Gần công viên Tao Đàn",                     // optional (detailed address)
  "latitude": 10.7769,                                      // optional
  "longitude": 106.7009,                                    // optional
  "tags": ["lost", "husky", "urgent"],                     // optional
  "petId": null,                                            // optional (link existing pet)
  
  // Pet info (if creating new pet along with post)
  "pet": {
    "name": "Max",                                          // optional
    "breed": "Siberian Husky",                              // optional
    "age": 36,                                              // optional (months)
    "gender": "MALE",                                       // optional: MALE|FEMALE
    "color": "Trắng xám",                                   // optional
    "size": "LARGE",                                        // optional: SMALL|MEDIUM|LARGE
    "weight": 28.0,                                         // optional
    "isNeutered": true,                                     // optional
    "isVaccinated": true,                                   // optional

    "specialNeeds": null,                                   // optional
    "bio": "Max là một chú Husky..."                       // optional

}

Request Body (multipart/form-data for images):
- postData: JSON string of above object

================================================================================
                           5. UPDATE POST
================================================================================
Update an existing post

Endpoint: PUT /api/v1/posts/{id}
Auth: Required (Bearer Token)
Note: Only owner can update their post

Path Parameters:
  - id: post ID

Request Body:
{
  "title": "Tiêu đề mới",                    // optional
  "description": "Mô tả mới...",             // optional
  "petType": "Husky",                        // optional
  "status": "FOUND",                         // optional (change status, e.g., LOST -> FOUND)
  "city": "TP. Hồ Chí Minh",                // optional
  "district": "Quận 2",                      // optional
  "location": "Địa chỉ mới",                 // optional
  "latitude": 10.8000,                       // optional
  "longitude": 106.7500,                     // optional
  "tags": ["found", "husky"],                // optional
  "isActive": true,                          // optional (activate/deactivate)
  
  // Update pet info
  "pet": {
    "name": "Max",
    "color": "Trắng xám đậm"
  }
}

Response 200 OK:
{
  "success": true,
  "data": { ... full post object ... },
  "message": "Cập nhật bài đăng thành công"
}

Response 403 Forbidden:
{
  "success": false,
  "error": "FORBIDDEN",
  "message": "Bạn không có quyền chỉnh sửa bài đăng này"
}

================================================================================
                         DATABASE MAPPINGS
================================================================================

pet_posts table:
- id -> id
- title -> title
- slug -> slug (auto-generated, unique)
- description -> description
- image -> image (thumbnail URL)
- pet_type -> petType
- status -> status (LOST, FOUND, FOR_ADOPTION, RESCUE)
- city -> city
- district -> district
- location -> location (detailed address)
- latitude -> latitude
- longitude -> longitude
- views -> views
- featured -> featured
- is_active -> isActive
- tags -> tags (JSONB)
- created_at -> createdAt
- updated_at -> updatedAt
- user_id -> user (relation)
- pet_id -> pet (relation, optional)

media table:
- id -> id
- image_url -> imageUrl
- is_thumbnail -> isThumbnail
- post_id -> postId (relation)

pets table:
- id -> id
- name -> name
- type -> type
- breed -> breed
- age -> age (months)
- gender -> gender (MALE, FEMALE)
- color -> color
- size -> size (SMALL, MEDIUM, LARGE)
- weight -> weight
- is_neutered -> isNeutered
- is_vaccinated -> isVaccinated
- personality -> personality (JSONB)
- special_needs -> specialNeeds
- bio -> bio
- profile_photo -> profilePhoto


================================================================================
                         SLUG GENERATION RULES
================================================================================

Slug is auto-generated from title:
1. Convert to lowercase
2. Remove Vietnamese diacritics (á -> a, đ -> d, etc.)
3. Replace spaces and special chars with hyphens
4. Remove consecutive hyphens
5. Append timestamp to ensure uniqueness

Example:
  "Chó Husky mất tích tại Q.1" -> "cho-husky-mat-tich-tai-q1-1703234567890"


================================================================================
                         BUSINESS RULES
================================================================================

1. Users can only edit/delete their own posts (user_id = current_user.id)

2. Image limits:
   - Max 5 images per post
   - Max 5MB per image
   - Supported formats: JPG, PNG, WEBP

3. Slug must be unique - auto-generated with timestamp

4. When status changes from LOST to FOUND:
   - Send notification to users who saved/contacted about this post

5. Soft delete: isActive = false instead of actual delete

6. View count: Increase only once per user session (track by IP or user_id)

7. Luồng đăng bài:
   - Bài đăng mới hiển thị công khai NGAY sau khi tạo
   - KHÔNG có tính năng lưu nháp (draft)
   - KHÔNG cần duyệt bài
